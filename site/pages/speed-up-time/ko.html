앱 하나의 시계만 더 빠르게 돌리기

시간을 옮길 수 없다면 30일 체험 기간이 만료되는 데 30일이 걸립니다. 흔한 조언은 시스템 시계를 앞으로 미는 것인데, 관리자 권한이 필요하고 컴퓨터의 다른 모든 프로그램까지 끌려옵니다. 이 도구는 대신 프로세스 하나만 옮깁니다.

얼마나 빠르게

정수 배율을 고르세요. 앱의 시계는 세션이 시작된 시점부터 실제 시계보다 그 배수만큼 빠르게 흐릅니다.

배율실제 1분이 되는 것용도
x60한 시간매시간 작업, 세션 타임아웃, 토큰 수명
x1440하루일 단위 전환, 30분 만에 끝나는 30일 체험 기간
x4320030일 체험 기간이 글을 읽는 동안 체험 기간 전체가 끝나는 것을 지켜보기
x5256001년연간 갱신, 인증서 만료
x1000000약 1.9년상한
 
# 지금의 실제 시간에서 시작해 1분에 하루씩 돌리기
chrono run "C:\apps\test.exe" --mode x1440

# 선택한 날짜에서 시작해 거기서부터 가속하기
chrono run "C:\apps\test.exe" --at 2027-12-01T09:00:00 --mode x1440

# 반대로 시계를 완전히 멈춰 두기
chrono run "C:\apps\test.exe" --mode frozen

사람들이 걸려 넘어지는 부분: 시계는 두 가지입니다

벽시계, 즉 DateTime.Now와 그에 해당하는 것들이 반환하는 값을 빠르게 한다고 해서 그것만으로 카운트다운이 빨라지지는 않습니다. 이는 애플리케이션이 운영 체제에 던질 수 있는 서로 다른 두 질문이며, 많은 소프트웨어가 “30일”을 앞의 것이 아니라 뒤의 것으로 잽니다.

그래서 지속 시간 축, 즉 틱 수, 슬립, 대기, 타이머는 별도의 스위치입니다.

  • --scale-duration은 슬립, 대기, 타이머도 세션 시계에 올립니다. 이것이 없으면 x1440은 달력만 앞으로 질주시키고 5초 타이머는 여전히 실제 5초가 걸립니다.
  • --scale-qpc는 추가로 고해상도 카운터에도 배율을 적용합니다. Python 3.13+의 monotonic, .NET의 Stopwatch, Java의 nanoTime이 경과 시간을 읽는 곳이며, 배율을 적용하면 테스트에서 렌더링이 불안정해졌기 때문에 기본값은 꺼짐입니다.

배율이 카운트다운에 아무 영향도 주지 않는 것처럼 보인다면 거의 항상 이것이 이유입니다. 

# 타이머 앱: 달력과 카운트다운을 모두 가속
chrono run "C:\apps\Timer.exe" --mode x60 --scale-duration

# 경과 시간을 고해상도 카운터로 재는 Python 또는 .NET 앱
chrono run "C:\apps\Job.exe" --mode x60 --scale-duration --scale-qpc

다시 시작하지 않고 속도 바꾸기

배율은 세션 도중에 바꿀 수 있으며, 시계는 점프하는 대신 기준점을 다시 잡기 때문에 속도가 내려가도 뒤로 가는 일이 없습니다. 시계를 곧바로 점프시킬 수도 있습니다. 앞으로도, 노트북이 시간 서버와 다시 동기화한 뒤처럼 뒤로도 가능하며, 이는 보호 장치 없이 경과 시간을 재는 모든 것을 깨뜨리는 경우입니다. 

# x60으로 실행하다가 2초 뒤에 x1440으로 전환
chrono run "C:\apps\test.exe" --mode x60 --set-after 2:1440

# 실행하다가 5초 뒤에 시계를 선택한 시점으로 점프
chrono run "C:\apps\test.exe" --jump-after 5:2028-01-01T00:00:00

하지 않는 일

  • 시스템 시계는 건드리지 않습니다. 이것은 한계가 아니라 요점입니다. 다만 서버, 데이터베이스, 다른 컴퓨터에서 시간을 읽는 것은 영향을 받지 않는다는 뜻이며, 그런 일이 생기면 감사가 알려 줍니다.
  • 점프는 앱이 보는 시간을 바꾸는 것이지, 앱이 깨어나는 시점을 바꾸지는 않습니다. 이미 커널에 넘겨진 타이머는 실제 시간으로 동작합니다. 대부분의 앱은 시계를 폴링하므로 실제로는 점프가 통하지만, 전부 그런 것은 아닙니다.
  • 시간을 느리게 하지는 못합니다. 배율은 1 이상의 정수이며, 0에서 멈춘 시계가 있을 뿐입니다.

Chrono Mock herunterladen

Zwei Builds derselben Engine: ein Fenster zum Erkunden, eine Kommandozeile für CI. Beide lassen sich überall entpacken und starten - ohne Installer, ohne Registry-Einträge, ohne Administratorrechte. Oder die signierte .msi für jedes Konto auf dem Rechner installieren: einmal Administratorrechte zum Installieren, keine zum Ausführen.

ChronoMock-app-win-x64.msi Die Desktop-Anwendung und die Kommandozeile, für jedes Konto auf dem Rechner installiert: ein Startmenüeintrag und chrono im PATH ~58 MB

Was Sie brauchen

  • Windows 10 oder Windows 11. Es gibt keinen Build für macOS oder Linux - unter Linux deckt libfaketime das schon gut ab.
  • Sonst nichts. Der Desktop-Build bringt seine eigene Laufzeitumgebung mit, der Kommandozeilen-Build gar nichts.
  • 32-Bit- und 64-Bit-Anwendungen werden unterstützt. Das Paket enthält beide und wählt die Variante, die zur Anwendung passt, auf die Sie es richten.

ARM64 ist bis einschließlich Version 1.0 nicht vorgesehen, und gepackte Store-Anwendungen (UWP und MSIX) werden nicht unterstützt - ihr Startmodell lässt es nicht zu.

Starten

Entpacken Sie das Archiv und starten Sie dann ChronoMock.exe für das Fenster oder chrono.exe für die Kommandozeile. Eine erste Sitzung besteht aus drei Entscheidungen: welche Anwendung, welcher Zeitpunkt und wie schnell die Uhr laufen soll. 

# Eine Anwendung so ausführen, als wäre es die letzte Sekunde des Jahres 2027
chrono run "C:\apps\test.exe" --at 2027-12-31T23:59:59

# Dasselbe, mit einer Uhr, die einen Tag pro Minute läuft
chrono run "C:\apps\test.exe" --at 2027-12-31T23:59:59 --mode x1440

Zwei Dinge vorab lesen

Sichern Sie das Datenverzeichnis der Anwendung, bevor Sie die erste Sitzung in der Zukunft starten.

Eine Anwendung, die im Jahr 2028 läuft, schreibt 2028er Daten überall dorthin, wo sie etwas speichert: in ihre Datenbank, ihre Konfiguration, ihren Cache, ihre Lizenzdatei. Diese Werte bleiben dort, nachdem Sie zur echten Zeit zurückgekehrt sind. Bei Software mit Lizenzschutz kann das endgültig sein - „Uhrenrückstellung erkannt, Lizenz ungültig“ ist ein gängiges Muster der Branche, und es tut genau das, wofür es gebaut wurde.

Chrono Mock räumt hinter sich auf. Hinter der Anwendung, die Sie getestet haben, kann es nicht aufräumen.

Ihr Virenschutz schlägt möglicherweise an - das ist zu erwarten.

Die Zeit wird verschoben, indem eine kleine Bibliothek in den Zielprozess eingeschleust wird. Das ist eine legitime, dokumentierte Windows-Technik - und zugleich eine, die Schadsoftware nutzt. Deshalb melden Microsoft Defender und andere die eingeschleuste Bibliothek womöglich oder blockieren die Injektion ganz. Es ist ein Fehlalarm, ausgelöst durch die Technik.

Wenn eine Sitzung nicht starten will und Defender eine Bedrohung meldet, schließen Sie die Bibliothek aus, nicht den Ordner: Wählen Sie in der Windows-Sicherheit Datei und geben Sie den vollständigen Pfad zu chrono_hook.dll an. Ein Ordnerausschluss würde verhindern, dass im Verzeichnis, aus dem das Tool injiziert, überhaupt etwas geprüft wird. Oder führen Sie es auf einem Rechner aus, auf dem Sie das dürfen. Die eingeschleuste Bibliothek wird aus dem Code in diesem Repository unter GPL-3.0 gebaut - Sie können sie selbst neu bauen. Der Chromium- und Electron-Modus injiziert gar nicht und ist nicht betroffen.

Was es zurücklässt

Nichts in Ihrem System: keine dauerhaften Hooks, keine Registry-Einträge und nichts außerhalb des eigenen Ordners - bis auf drei Dinge, die es Ihnen nennt: den Sitzungsverlauf und das Diagnoseprotokoll, die nach %LOCALAPPDATA%\ChronoMock\ wandern, wenn der Ordner des Tools nicht beschreibbar ist, und, bei einem Electron- oder Chromium-Ziel, ein Wegwerf-Browserprofil unter %TEMP%, das am Ende der Sitzung gelöscht wird und, falls das nicht gelang, in der Sitzungszusammenfassung genannt wird.

Das beschreibt die ZIP-Dateien. Der Installer ist die Ausnahme und sagt, was er hinzufügt: das Programm in Program Files, einen Startmenüeintrag, chrono im PATH des Rechners, einen Eintrag unter Einstellungen, Apps und den Schlüssel HKLM\Software\DonislawDev\Chrono Mock. Das Deinstallieren entfernt alles davon und lässt %LOCALAPPDATA%\ChronoMock\ in Ruhe. Eine weitere Option, standardmäßig aus, schreibt für die Dauer einer Sitzung einen Registry-Wert und entfernt ihn danach wieder: --elevated-embedded.

Es verbindet sich nie mit dem Internet, führt kein Konto und sendet keine Telemetrie.

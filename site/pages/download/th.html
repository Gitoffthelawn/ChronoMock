ดาวน์โหลด Chrono Mock

สองบิลด์ของเอนจินเดียวกัน คือหน้าต่างสำหรับสำรวจและบรรทัดคำสั่งสำหรับ CI แตกไฟล์อย่างใดอย่างหนึ่งที่ไหนก็ได้แล้วรัน โดยไม่ต้องมีตัวติดตั้ง ไม่มีรายการในรีจิสทรี และไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ หรือจะติดตั้ง .msi ที่ลงนามแล้วสำหรับทุกบัญชีบนเครื่องก็ได้ ต้องใช้สิทธิ์ผู้ดูแลระบบเพียงครั้งเดียวตอนติดตั้ง และไม่ต้องใช้ตอนรัน

รับรุ่นล่าสุด ดูโค้ดบน GitHub
ไฟล์คืออะไรขนาด
ChronoMock-app-win-x64.zip แอปเดสก์ท็อป ครบในตัว - ไม่ต้องติดตั้ง .NET ~69 MB
ChronoMock-app-win-x64.msi แอปพลิเคชันเดสก์ท็อปและบรรทัดคำสั่ง ติดตั้งสำหรับทุกบัญชีบนเครื่อง โดยมีรายการในเมนู Start และ chrono ใน PATH ~58 MB
ChronoMock-cli-win.zip เฉพาะเครื่องมือบรรทัดคำสั่ง สำหรับ CI และสคริปต์ ~1.6 MB

สิ่งที่คุณต้องมี

  • Windows 10 หรือ Windows 11 ไม่มีบิลด์สำหรับ macOS หรือ Linux - บน Linux มี libfaketime ที่ทำหน้าที่นี้ได้ดีอยู่แล้ว
  • ไม่ต้องมีอะไรอีก บิลด์เดสก์ท็อปมีรันไทม์มาในตัว ส่วนบิลด์บรรทัดคำสั่งไม่ต้องพกอะไรมาเลย
  • รองรับทั้งแอป 32 บิตและ 64 บิต แพ็กเกจมีให้ทั้งสองแบบ และเลือกตัวที่ตรงกับแอปที่คุณชี้ไป

ARM64 อยู่นอกขอบเขตจนถึงเวอร์ชัน 1.0 และแอปที่แพ็กเกจจาก Store (UWP และ MSIX) ไม่รองรับ - โมเดลการเปิดของมันไม่อนุญาต

วิธีรัน

แตกไฟล์ แล้วรัน ChronoMock.exe สำหรับหน้าต่างโปรแกรม หรือ chrono.exe สำหรับบรรทัดคำสั่ง เซสชันแรกคือการตัดสินใจสามอย่าง: แอปไหน ช่วงเวลาใด และนาฬิกาควรเดินเร็วแค่ไหน

# รันแอปเสมือนว่าเป็นวินาทีสุดท้ายของปี 2027
chrono run "C:\apps\test.exe" --at 2027-12-31T23:59:59

# เหมือนกัน แต่ให้นาฬิกาเดินหนึ่งวันต่อหนึ่งนาที
chrono run "C:\apps\test.exe" --at 2027-12-31T23:59:59 --mode x1440

สองเรื่องที่ควรอ่านก่อน

สำรองไดเรกทอรีข้อมูลของแอปไว้ก่อนเซสชันแรกที่ใช้วันที่ในอนาคต

แอปที่รันอยู่ในปี 2028 จะเขียนวันที่ปี 2028 ลงทุกที่ที่มันเก็บข้อมูล: ฐานข้อมูล การตั้งค่า แคช ไฟล์ไลเซนส์ ค่าเหล่านั้นยังคงอยู่ที่นั่นหลังจากคุณกลับมาใช้เวลาจริง สำหรับซอฟต์แวร์ที่มีการป้องกันไลเซนส์ นี่อาจถาวร - “ตรวจพบการย้อนนาฬิกา ไลเซนส์ถูกทำให้เป็นโมฆะ” เป็นรูปแบบมาตรฐานของวงการ และมันจะทำตามที่ถูกออกแบบมาทุกประการ

Chrono Mock เก็บกวาดสิ่งที่ตัวเองทิ้งไว้ แต่ไม่สามารถเก็บกวาดสิ่งที่แอปที่คุณทดสอบทิ้งไว้ได้

โปรแกรมป้องกันไวรัสของคุณอาจแจ้งเตือน และนั่นเป็นเรื่องที่คาดไว้แล้ว

การเลื่อนเวลาทำโดยการฉีดไลบรารีขนาดเล็กเข้าไปในโพรเซสเป้าหมาย นั่นเป็นเทคนิคที่ถูกต้องและมีเอกสารของ Windows - และเป็นเทคนิคที่มัลแวร์ใช้ด้วย Microsoft Defender และโปรแกรมอื่นจึงอาจแจ้งเตือนไลบรารีที่ถูกฉีด หรือบล็อกการฉีดไปเลย นี่คือการแจ้งเตือนผิดพลาดที่เกิดจากตัวเทคนิค

หากเซสชันไม่ยอมเริ่มและ Defender รายงานภัยคุกคาม ให้ยกเว้นไลบรารีแทนที่จะยกเว้นทั้งโฟลเดอร์: เลือก File ใน Windows Security แล้วใส่พาธเต็มของ chrono_hook.dll การยกเว้นโฟลเดอร์จะทำให้ไม่มีอะไรถูกสแกนในไดเรกทอรีเดียวกับที่เครื่องมือใช้ฉีด หรือรันบนเครื่องที่คุณได้รับอนุญาตให้ทำเช่นนั้น ไลบรารีที่ถูกฉีดสร้างจากโค้ดในรีโพซิทอรีนี้ภายใต้ GPL-3.0 - คุณบิลด์เองใหม่ได้ ส่วนโหมด Chromium และ Electron ไม่ฉีดอะไรเลยและไม่ได้รับผลกระทบ

สิ่งที่มันทิ้งไว้

ไม่มีอะไรในระบบของคุณ: ไม่มีฮุกถาวร ไม่มีรายการในรีจิสทรี และไม่มีอะไรนอกโฟลเดอร์ของมันเอง ยกเว้นสามอย่างที่มันจะบอกชื่อให้คุณ - ประวัติเซสชันและบันทึกการวินิจฉัย ซึ่งย้ายไปที่ %LOCALAPPDATA%\ChronoMock\ เมื่อโฟลเดอร์ของเครื่องมือเองเขียนไม่ได้ และสำหรับเป้าหมาย Electron หรือ Chromium คือโปรไฟล์เบราว์เซอร์ชั่วคราวใต้ %TEMP% ซึ่งถูกลบเมื่อเซสชันจบ และจะรายงานไว้ในสรุปของเซสชันหากลบไม่ได้

นั่นอธิบายไฟล์ zip ส่วนตัวติดตั้งเป็นข้อยกเว้นและบอกว่ามันเพิ่มอะไร คือโปรแกรมใน Program Files รายการในเมนู Start chrono ใน PATH ของเครื่อง รายการในการตั้งค่า แอป และคีย์ HKLM\Software\DonislawDev\Chrono Mock การถอนการติดตั้งจะลบทั้งหมดนี้และไม่แตะ %LOCALAPPDATA%\ChronoMock\ อีกตัวเลือกหนึ่งซึ่งปิดไว้เป็นค่าเริ่มต้นจะเขียนค่าในรีจิสทรีตลอดช่วงเซสชันแล้วลบออกหลังจากนั้น คือ --elevated-embedded
